What This Model Can Explain

Use the dashboard to tell four connected stories: who got in, how the rounds evolved, where competition was strongest, and whether different groups saw different outcomes.

For dynamic admissions, you can also export round-specific result and trace files from Julia and reuse this same visual pattern for each batch.
